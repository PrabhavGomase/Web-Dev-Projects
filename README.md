# Web Development Projects

This repository contains beginner web development projects built using HTML, CSS, and JavaScript.

## Projects

### 1. Todo App
A task management application that allows users to:
- Add tasks
- Mark tasks as completed
- Filter tasks (All / Pending / Completed)

Technologies used:
- HTML
- CSS
- JavaScript
- LocalStorage

---

### 2. Weather Dashboard
A weather application that fetches real-time weather data using an API.

Features:
- Search weather by city
- Displays temperature, humidity, wind speed
- Dynamic UI updates

Technologies used:
- HTML
- CSS
- JavaScript
- Weather API

---

### 3. Sorting Algorithm Visualizer
A visual tool that demonstrates how sorting algorithms work.

Algorithms implemented:
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

Features:
- Adjustable speed
- Adjustable array size
- Visual comparison and swaps

Technologies used:
- HTML
- CSS
- JavaScript
